# Champ Pool — Fearless Draft

Small React + Vite app to list League of Legends champions and cross them off for fearless draft. Sessions can be saved to Supabase.

Quick start

1. Install dependencies

```bash
npm install
```

2. Create a `.env` file in project root with your Supabase values:

```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

3. Start dev server

```bash
npm run dev
```

Supabase schema

Run this SQL in the Supabase SQL editor to create the `sessions` table:

```sql
create table if not exists sessions (
  id bigint generated by default as identity primary key,
  name text,
  payload jsonb,
  created_at timestamptz default now()
);
```

Notes
- The app fetches champion data from Riot Data Dragon at runtime.
- Sessions store the list of checked champion ids in the `payload` JSON.
